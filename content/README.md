# Контент канала

Пул постов для `@qazaqcinema_kz`: один YAML на рубрику, картинки — в `images/`, шрифты для
карточек — в `fonts/`. `holidays.yaml` — поздравления с праздниками: slug элемента = slug
праздника из `app/domain/channel/holidays.py`, иначе поздравление не найдётся (тест
`tests/test_holidays.py` это проверяет). Формат элемента — в докстринге
`app/infrastructure/content/yaml_loader.py`; сетка слотов и ротация — в
`app/domain/channel/content/plan.py` (см. CLAUDE.md, «Публичный канал»).

Заливка: `./start.sh seed` (идемпотентно, upsert по `slug`).
Проверка YAML без БД: `./start.sh seed --check`.

Жұмбақ дня: 396 вопросов — 44 фольклорных в `zhumbaq.yaml` и 352 новых авторских в
`zhumbaq_original.yaml`. У авторских указан источник `QazaqCinema · авторлық жұмбақ`;
они не выдаются за фольклор. Темы: природа, животные, растения, дом, язык, техника,
цифровой мир, еда, традиции, космос, спорт и логика. `accept` содержит допустимые ответы.

Открытые загадки публикуются только по кнопке или `/jumbak` в группе обсуждений. Все
старые кнопки используют один callback `jumbak:today` без даты и id вопроса. Первый
запрос за местные сутки создаёт пост, повторные показывают сегодняшнюю загадку
нажавшему; команда возвращает ссылку на общий пост. В личке команды молчат.
Три попытки до 21:00 Алматы, 3/2/1 балла; `/answer` без аргумента после 21:00 публикует
один разбор, `/rating` показывает недельный рейтинг. Автоматического разбора нет.

Анонс в `announcements.yaml` публикуется вручную, только после push, деплоя, загрузки
банка и проверки бота. Команда внутри обновлённого работающего контейнера:

```bash
ENV_FILE=.env.prod docker compose --env-file .env.prod exec -T bot \
  python -m app.tools.announce_riddles --publish
```

Она проверяет размер банка и схему попыток, отправляет анонс с той же общей кнопкой
и закрепляет его. Повторный запуск не создаёт второй пост; если закрепление не удалось,
повторяется только оно. Без `--publish` отправки нет.
