# Universe environment

Created with the built-in image_gen tool for Dala Dauleti. The WebP is an encoding of
the generated illustration; game cells, buildings and tokens are separate React/SVG components.

## Prompt

Use case: stylized-concept. Asset type: wide atmospheric background illustration for a real, clickable 3D Kazakh economic board game named Dala Dauleti. Create a beautiful polished miniature universe of Kazakhstan: a dreamlike archipelago of small floating garden islands above soft clouds, turquoise rivers with tiny waterfalls, sunlit ochre paths, lush rounded trees, distant blue snow-capped mountains, a few small ivory yurts with ornamental warm terracotta roofs, and distant turquoise domed town silhouettes. Style: premium stylized 3D game environment concept art, tactile handcrafted materials, richly detailed, lively, warm, welcoming, sophisticated colors and cinematic soft sunlight; teal, sage green, turquoise and golden peach light. Wide 16:9 panorama. The main middle 60 percent must remain open airy pale turquoise/cream cloud space so that an actual 3D board can be composited in front; keep detailed miniature islands along far left, far right, and distant upper horizon, all smaller than the foreground game. Soft atmospheric perspective. No text, no lettering, no logos, no watermark, no UI, no playing board, no dice, no flat vector style, no outer-space planets, no dark space background.
